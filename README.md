# BibleRats v0.2

Mudanças principais:
- novo visual editorial/minimalista mais refinado
- logo do rato como ícone oficial do PWA
- ícones normal + maskable para Android adaptar círculo/squircle/quadrado arredondado
- apple-touch-icon para iPhone/iPad
- layout responsivo
- favorito por estrela separada; tocar no capítulo só marca/desmarca como lido
- desmarcar um capítulo remove seu favorito automaticamente
- Home resumida: em andamento + não iniciados + até 3 destaques
- Panorama ampliado
- popup de instalação com X
- Android/Chromium usa o prompt nativo de instalação quando disponível
- iPhone/iPad mostra a instrução correta para adicionar ao ecrã principal
- migração automática dos dados locais da v0.1

## GitHub Pages
1. Substitua os arquivos antigos pelos desta versão.
2. Confirme que `index.html` está na raiz.
3. Settings > Pages > Deploy from a branch.
4. Branch `main`, pasta `/ (root)`.
5. Salve e aguarde a publicação.

Se o PWA mostrar a versão anterior após atualizar, feche e reabra o app ou atualize a página no navegador uma vez.
