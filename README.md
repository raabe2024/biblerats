# BibleRats v0.3

Novidade principal: instalação PWA diretamente pela Home.

- Quando o navegador disponibiliza a instalação, aparece um card “Instale o BibleRats”.
- Ao tocar em “Instalar”, abre a confirmação oficial do Android/Chrome.
- A instalação só acontece após o consentimento da pessoa.
- Depois de instalado e aberto como app (`standalone`), o card não aparece.
- O X fecha o convite apenas durante a sessão atual.
- O botão de instalação nas Configurações continua disponível quando suportado.
- Mantém as correções da V0.2: sem salto de scroll ao marcar capítulos e duplo toque para favorito.
- Mantém `biblerats-v01` como chave dos dados para preservar o progresso já existente.

## Atualização no GitHub
Substitua os arquivos do repositório pelos desta versão e faça commit na branch `main`.
GitHub Pages fará o novo deploy automaticamente.
